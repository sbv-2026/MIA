# Tổng quan hệ thống

DemoMSBWeb và DemoMSBApp là hai Host độc lập dùng chung demo banking API thuộc DemoMSBWeb. MIAAssistant là deployment thứ ba, sở hữu UI/Agent/contracts và chỉ nhận context read-only. MIA POC được đóng băng tại `poc-v1` và không nằm trong deployment mới.

Local ports: POC `8080`, DemoMSBWeb `8081`, MIAAssistant `8090`.
